# Задание

## Контекст

Это приложение `referral` для Webasyst: клиент получает реферальную ссылку, приглашает друзей, а когда друг оформляет первый заказ, клиент получает бонусы на бонусный счёт и может тратить их на заказы. Сотрудник в бэкенде смотрит счета и корректирует бонусы. Код сгенерировал AI-ассистент по задаче «сделай реферальную программу». В прод он ещё не попадал.

Проект работает на **старой версии Webasyst**, поэтому решения должны использовать только стабильный API фреймворка без новых возможностей.

Твоя задача: **подготовить код к мержу**.

## Бизнес-требования

1. Все действия в личном кабинете доступны **только авторизованным** клиентам, и только по **своему** счёту и **своим** приглашениям. Реферальная ссылка `r/<код>/`, по которой переходит друг, публичная.
2. Реферальный код **случайный**, не угадывается по времени и не повторяется между клиентами.
3. Ссылка `r/<код>/` может вести только **на наш сайт**: параметр `return` не должен уводить на чужие адреса. Запоминание «кто пригласил» не должно позволять подделать данные в cookie и не должно запускать чужой код на сервере.
4. Бонус начисляется пригласившему **один раз** за **первый заказ друга**, **не самому себе**, в размере 10% от суммы заказа **по данным нашего заказа**, а не по данным из браузера.
5. Бонусы **целые** и никогда не уходят в минус: нельзя списать больше, чем на счёте, нельзя списать отрицательное число, два одновременных списания не уводят счёт в минус.
6. Клиент может указать адрес для уведомлений о регистрации друзей. Проверочный запрос на этот адрес не должен обращаться к **внутренним адресам сервера и сети** и не должен показывать клиенту тело чужого ответа.
7. Приглашение не раскрывает, есть ли адрес в базе клиентов. Внутренняя заметка и статус приглашения клиенту не показываются и не принимаются от него.
8. Сотрудник работает со счетами и корректирует бонусы **только с правом «Работа с реферальной программой»**; каждая корректировка записывается в историю, а корректировка не может увести счёт в минус.
9. Текст приглашений везде выводится как текст, а не как HTML.

## Что нужно сделать

- Найти и исправить проблемы в PHP-коде, шаблоне и JS.
- Привести код в соответствие с бизнес-требованиями.
- Объяснить, как ты проверишь, что исправления работают.

Всё за 25 минут сделать не обязательно. Расставь приоритеты: начни с самого важного.
